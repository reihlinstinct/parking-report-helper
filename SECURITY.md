# Security policy

## Supported versions

Only the latest release of the `main` branch is supported. Security fixes are made there.

| Version | Supported |
| ------- | --------- |
| latest `main` (0.2.x) | yes |
| older | no |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/reihlinstinct/parking-report-helper/security/advisories/new).

Do not open a public issue for a security problem. Never include real plate numbers,
reporter details, API keys or other private data in a report; use synthetic values.

You can expect an acknowledgement within a few days. Confirmed issues are fixed on `main`
and disclosed in a GitHub security advisory once a fix is available.
